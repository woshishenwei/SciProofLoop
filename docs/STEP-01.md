# 第一步：证明平台可用、场景可验

周期：2026-10-23 至 10-29（内部目标）。本周不要求完整多 Agent 系统，不要求实现 MCP 服务。

## 队员 1：AgentArts 最小链路（8h 上限）

1. **1h**：确认中山大学/广东赛区通知入口、官方报名及作品提交日期。拿不到明确日期就记录「待确认」与咨询渠道；不要填猜测日期。确认 AgentArts 账号、区域、版本与可用资源，不在仓库记录凭证。
2. **2h**：在 AgentArts 创建 SciProofLoop 的测试应用，完成一次真实模型调用。保存配置记录与脱敏运行截图。
3. **2h**：把队员 2 的一张文献卡导入 AgentArts 知识库，绑定到应用并提问一个卡片中可回答的问题，保存检索命中及回答证据。只有摘要时不得回答全文未提供的细节。
4. **1h**：记录当前账号可见的多 Agent、MCP、评估、发布能力和限制。不能仅凭产品宣传认定本账号已开通。
5. **1h**：与队员 2 联验，填交付模板。
6. **1h**：缓冲。权限问题排查累计达到 2h 就记录错误与所需操作，不继续无界排查。

交付：在 `deliverables/step-01.md` 填写平台、日期及运行证据；脱敏图片可放 `deliverables/evidence/`。

## 队员 2：小场景与可靠样例（6h 上限）

1. **1h**：选择两人熟悉的一个小主题，写一句使用场景。若没有偏好，可从「梯度下降在二次函数上的收敛」开始；这是候选示例，不预设你们的研究领域。
2. **2h**：选 3 篇真实相关论文，逐篇记录标题、作者、arXiv ID/DOI、链接、版本/日期、阅读范围（摘要或全文）、方法、结论、结论所在段落/章节。优先完成第一张卡片交给队员 1；摘要没有的信息写「未核验」。
3. **1h**：准备 3 条公式核验样例：正确表达式、明确错误且能给反例的表达式、缺少条件不能直接判定的表达式。写明变量域、假设和预期结果。可用 `(x+1)^2=x^2+2x+1`、`(x+1)^2=x^2+1`（x=1 反例）、`sqrt(x^2)=x`（实数域需补充非负条件）作为起始样例；这些是独立基准，不得冒称来自论文。
4. **1h**：与队员 1 联验，核对知识库回答中的引用是否真的支持结论。
5. **1h**：缓冲。

交付：3 张文献卡（`deliverables/papers/`）和 3 条公式样例（填写交付模板即可），无需开发工具代码。

## 联验通过标准

- [ ] 一个明确小主题，3 张可追溯文献卡，摘要/全文边界清楚。
- [ ] 3 条数学样例有明确变量域、假设及预期结果。
- [ ] AgentArts 上真实完成一次「知识库检索 → 回答」，可查看来源与运行记录。
- [ ] 记录账号版本、区域和可用功能；未验证能力明确标记。
- [ ] 报名与作品提交日期分别记录，未知项明确标记。

若平台权限阻塞，允许先交付样例与阻塞证据，但 M0 不能标为完成。回传交付文档、截图或提交链接，以及各自实际耗时；下一步据此细化，不提前追加任务。
