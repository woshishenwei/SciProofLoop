# 研证环 · SciProofLoop

**从文献证据到计算核验，让科研结论有据可查。**

面向第十一届华为 ICT 大赛（2026–2027）创新赛赛题 2 的科研工作流助手。团队：中山大学，广东赛区；开发预算：队员 1 每周 8 小时，队员 2 每周 6 小时。

## 当前状态

项目处于初始化与平台可行性验证阶段，尚未实现或部署 Agent。仓库中的架构、指标和排期均为设计目标，不能作为已完成能力宣传。

## 第一版做什么

只服务一个团队熟悉的数学/计算研究小主题，完成「检索论文 → 保存证据 → 提出可计算命题 → 调用工具核验 → 返回带引用和限制条件的报告」。

- **总控 Agent**：在 AgentArts 中理解请求、路由任务、汇总证据与计算结果。
- **文献 Agent**：检索 arXiv，生成带来源的文献卡，接入 AgentArts 知识库，支持按主题增量查询。
- **计算 Agent**：通过 AgentArts MCP 调用 SymPy 工具，核验受限表达式、寻找反例、运行固定模板数值实验。

第一版暂不做 Lean4、任意代码自动执行、Wolfram Alpha 付费接入或通用科研平台。实验代码生成和证明草稿留待核心闭环验收后评估。

## 平台边界

智能体构建、总控路由、多智能体编排、工具绑定、知识库接入、评估与发布部署必须在 **华为云 AgentArts** 完成。仓库保存提示词、平台配置记录、可导出资产、工具实现、评测样例与复现说明。

外部服务仅提供检索和确定性计算工具，不承载另一套 Agent 总控。不得用自建 LangChain/AutoGen 服务替代 AgentArts 编排。
